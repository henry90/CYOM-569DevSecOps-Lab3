# CISC/CYOM 569 - DevSecOps
# Lab 3: Create a Basic CI/CD Pipeline for a Hello World Web App

This project was completed as part of CISC/CYOM 569 - DevSecOps Lab 3. The lab focused on getting familiar with GitHub Actions, basic CI/CD workflows, and Docker.

For the GitHub Actions portion, I created and modified a workflow that runs when changes are pushed to the `main` branch. The workflow prints a simple message, displays information about the Ubuntu runner using `/etc/os-release`, and shows the system date and time.

For the Docker part, I created a simple **Hello World** webpage and a Dockerfile using the Nginx image. I then built the Docker image and ran it locally in a container, with the webpage available through `localhost:80`.

## Technologies Used

* GitHub and GitHub Actions
* Docker Desktop
* Visual Studio Code
* GitHub Desktop
* HTML
* Nginx
